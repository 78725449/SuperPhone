## 0. 当前现状速览（以代码为准）

- **端口全集（全固定不可调）**：网关 8080（web/API，TLS 可选 + 301 跳转）、注册 TCP 18081、隧道 TCP 18181；设备 VNC 5901、设备 H5 前端 5801。**46752 控制端口已删除**——命令经 5901 RFB 扩展消息承载（请求 type 0x50 / 响应 type 0x80，JSON 封装）。
- **网关 API**：`/api/state`、`/api/devices`（GET/POST）、`/api/devices/:id/{caps,configs,invoke,restart,ping}`、`/api/devices/batch/{invoke,configs,restart}`；**无通用 /command 端点**。设备命令字：invoke/set/restart/rfb.start/rfb.stop（隧道优先、注册通道回退；无隧道 4003 拒绝）。
- **前端**（`trollvnc-farm/web/`，原生 JS 无构建，缓存破坏 `?v=N`）：caps.js 自包含静态契约（**无上报 / 无元数据表 / 无运行时发现**）——KEY_DEFS **10 键**（RFB ks/code 直发）、BATCH_CAPS **20 项**、CONFIG_DEFS **37 项**；按压语义=单击立即发送 + 长按 800ms，双击/三击自然连点；卡片墙=hash 门控 + 变化拉图（不建 RFB 持久连接）；卡片 ⋯ 菜单仅「编辑/删除」；动作区已整区移除。
- **设备端命令注册表**（TRCapabilityRegistry）：`_registerControl:` 28 处调用（循环展开约 35 项）、`_registerConfig:` 44 处。screen.hash 注册在案（卡片墙消费）；**screen.diff / screen.waitStable 已删注册**（无消费方，0x50 op 为残留）。
- **键盘（方案 C，2026-08-16 定型）**：设备端 keyDown/keyUp 直接映射不补 Shift；前端 Shift 状态跟踪（kbdShiftHeld + 400ms 空闲自动释放）、特殊键 down+60ms 按住+up、删除/回车/粘贴前释放 Shift、英文/数字键值直发、中文/emoji 走 type.paste；粘贴输入无 changeCount 锚点；剪贴板首次复制=start 基线同步读取。
- **App 外壳**：UIKit 三 Tab，Tab2 控制 = `TVNCConsoleWebViewController`（WKWebView 加载网关 H5 手机控制台，https + 自签信任；原生设备墙 VC 已删）。
- **构建**：`.github/workflows/build.yml`（push `main` 分支，macOS CI，working-directory=TrollVNC），Theos 4 方案（bootstrap/legacy/rootless/roothide），可选 is_managed 打 Managed.plist；版本 0.0.1，产物 `TrollVNC_0.0.1.tipa`。**CI 多轮全绿、`npm test` 8 套件全绿**。
- **仓库**：2026-08-15 单仓库化（TrollVNC 从 gitlink 降级为普通子目录；旧 git 历史 `.git.bak` 不入库）。远程 `superphone` → github.com/78725449/SuperPhone.git，开发分支 `release`。
