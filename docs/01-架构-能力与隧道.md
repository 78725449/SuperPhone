## 1. 定位与愿景

- **内网自用 iOS 群控**：手机装一次、初始化一次，之后零操作；通过服务器（软路由）网页随时看到并操作所有设备（宪法 1.1）。
- **三端纯隧道**：PC web 控制台、手机 web 控制台、IPA 控制端（控制 Tab = WKWebView 容器加载网关 H5 手机控制台）三端画面与能力**一律走网关隧道**（仅 `source=register` 隧道设备）；直连 host 设备模式与 WS 直连回退已废弃（无隧道 4003 拒绝）。
- **能力层唯一地基**：所有设备操作走 RFB → IOHID 注入；手机自带 web（5801）与服务器控制台（8080）是同一地基上的两扇门。禁止任何前端自造输入协议。
- **前端静态契约**：前端 `caps.js` 自包含定义按键/配置/批量项（无上报、无元数据表、无运行时发现）；设备端注册表只存 executor，两端约定对齐。
- **内网自用边界**（宪法 1.3）：不设设备鉴权（网关侧保留 `FARM_TOKEN` 一行兜底）、不做过度 Agent 命令通道（批量启停/装 App 等）、不做 TLS 加固、多租户、审计、计费、商业化；配置命令（scale/帧率等）不在边界内，已实现。

## 2. 端口与连接模型

### 2.1 端口全集

> 端口表唯一真相源 = 开发宪法 2.7（8080 / 18081 / 18181 / 5901 / 5801 全固定不可调），本文不再重复。

> **46752 本地控制端口已删除（2026-08-12）**：命令不再经本地端口代理，全部并入 5901 RFB 扩展消息承载（请求 type 0x50 / 响应 type 0x80，JSON 封装）。Repeater 模式与 5500 端口亦已全链路删除。

### 2.2 连接模型

| 项 | 结论 |
|---|---|
| 连接方向 | 手机**主动注册**到网关（内网 IP 即身份），网关被动等待，不做轮询保活（宪法 2.1） |
| 注册/心跳 | TCP JSON（18081）：`register`（deviceId/name/vncPort/httpPort/screen/configs）→ `ack`；每 30s `hello`；90s 无心跳判离线；同 deviceId 只保留最新一条连接（宪法 7.1） |
| 隧道建立 | 注册成功后**自动开启 18181 隧道**，无需额外操作 |
| 控制端连接 | 三端控制台一律走网关隧道；直连回退已废弃，无隧道 4003 拒绝 |
| 局域网直连 | 5801/5901 服务本身在局域网内可不经网关直连（VNC/HTTP 服务层面，独立于控制台路径） |
| 在线状态 | 网关维护 = 注册连接存活 **或** 隧道连接存活（任一存活即在线） |
| 设备身份 | 首启生成 UUID（`DeviceUUID`）为唯一 `deviceId`，注册名用设备真实名称；身份唯一键 = deviceId（宪法 2.2/2.4） |
| 初始化 | 打开一次 App → 搜索网关（mDNS `_superphone-farm._tcp`）/手动输入 → 保存，之后全自动；Managed.plist 可预置网关 |
| 单会话约束 | 设备仅 1 条隧道 + 1 个 5901 连接，同设备同时仅 1 个活跃 VNC 会话；多会话共享 5901 会协议串流（noVNC `Unexpected server message (type N)`），网关新会话顶掉旧非 ctrl 会话（4001，宪法 6.10） |
| 鉴权 | 内网可信，不设设备鉴权；网关保留 FARM_TOKEN 兜底 |

## 3. 设备端命令接口与前端契约

### 3.1 能力注册表（TRCapabilityRegistry）

- **数据驱动注册表**：`_registerControl:` 28 处调用（含循环展开，实际注册约 35 项）、`_registerConfig:` 44 处（契约表单 37 项）。早期文档的 97/75 口径均已过时。
- **设备端只存 executor**，不向任何端下发定义；能力/配置契约由前端 `caps.js` 自包含定义承载（KEY_DEFS / BATCH_CAPS / CONFIG_DEFS）。
- **统一入口**：`invoke:capId:params:error:`（按 route 分派）、`setConfig:key:value:error:`（写 NSUserDefaults + 返回 reload 策略）。
- **路由类型（现状 4 类）**：

| route.type | 执行通道 | 示例 |
|---|---|---|
| `hid` | STHIDEventGenerator 直接调用 | home/power/volup/briup/keyboard |
| `touch` | 归一化坐标转原生像素 + HID | 画布直操（触控不进菜单） |
| `localcmd` | 5901 RFB 扩展消息（0x50/0x80，`_rfbCommand` 持久连接） | clients.*、screen.hash |
| `native` | Objective-C 方法直接调用 | clipboard.get/set、settings.*、sys.* |

- **执行链路**：控制端 → 网关 REST/WS/隧道 → 设备命令通道（TRGatewayClient）→ `TRCapabilityRegistry.invoke/setConfig` → executor（HID/Touch/LocalCmd/Native）→ 注入执行 → ACK 回网关与调用端。
- **两条操作路径**（宪法 4.3）：按键/触控走 **RFB 事件**（keysym/pointer 经 5901 直发，现成通道）；非按键能力（screen.hash、clipboard.get、settings.* 等）走**命令通道 `cmd=invoke`**。RFB 连接仅用于画面传输与按键/触控，能力执行不经 keysym 硬编码。

### 3.2 能力通道：5901 RFB 扩展消息

- 本地命令能力经 5901 RFB 扩展消息承载：client→server **type 0x50**，server→client **type 0x80**，JSON 负载。
- 执行体 `_rfbCommand`：持久 RFB 连接（127.0.0.1:5901）+ 握手 + `cap.hello {mgmt:true}` 管理标记——不计入 clients.count/list、不参与会话互斥、不推画面帧。
- 承载能力：`clients.count/list/disconnect/block/unblock/blocked.list`、`screen.hash` 等。
- **已删除**：`screen.diff`/`screen.waitStable` 注册（无消费方，0x50 op 为残留，invoke 不可达）；`subscribe on/off` 推送链路（H5 用轮询 hash）。

### 3.3 命令通道（网关 ↔ 设备）

> 命令字与 REST 端点唯一真相源 = 开发宪法 7.4（invoke/set/restart/rfb.start/rfb.stop/ping；隧道 FT_CMD 帧优先、注册通道 JSON 行回退；端点 `/api/state`、`/api/devices`、`/api/devices/:id/{caps,configs,invoke,restart,ping}`、批量端点；超时 504；无通用 /command），本文不再重复。

- **register 上报字段（现状）**：deviceId、name、vncPort、httpPort、screen（width/height）、configs（当前值快照）；**capabilities/capMetadata/configSchema 不再上报**（2026-08-13 起前端自包含静态契约）。
- restartHandler：`trollvncmanager` 启动 TRGatewayClient 时注入，`cmd=restart` 调 `[gWatchDog restart]`。

### 3.4 WS 端点

| 端点 | 用途 |
|---|---|
| `WS /ws/vnc/:id` | 画面 RFB 桥接（隧道桥接，无直连分支） |
| `WS /ws/control/:id` | AI 工具/自动化流式接口：一个 WS 完成 query/set/invoke 全流程（契约保留） |

> REST 端点清单（单台 + 批量、超时 504 语义）见宪法 7.4；**无通用 `/command` 端点**（已删）；无 `/ws/register` 端点（单通道铁律）。

### 3.5 配置与热重载

- **配置唯一来源**：设置页（NSUserDefaults）/ Managed.plist 预置 / 网关 configs 命令通道；5801/5901 不承载任何配置 API（宪法 2.10）。
- 前端 `CONFIG_DEFS` 37 项配置表单（与设备端 `_registerConfigSchemas` 对齐），按 reload 分区渲染。
- **reload 语义**：

| reload | 含义 | 示例 |
|---|---|---|
| `instant` | 写入即生效（下次读取自动用新值） | clipboardEnabled、viewOnly、naturalScroll、Notifications |
| `hot` | 热重载：trollvncserver 经 `tvReloadConfigForKey` 更新 C 全局变量，或直接设属性 | Scale（触发 framebuffer 重建 + 重新 register）、FrameRateSpec、OrientationSync、Watchdog 三项、HIDKeepAliveInterval |
| `gateway` | 改变注册字段，触发重新 register | GatewayHost、GatewayToken、BonjourEnabled |
| `restart` | 涉及端口/认证/RFB 协议头，watchdog 重启 | BindHost、HttpDir、FullPassword/ViewOnlyPassword、TileSize、MaxRects、AsyncSwap、SslCertFile/KeyFile、Enabled |

- **密码安全**：FullPassword/ViewOnlyPassword 不上报明文，改为 `hasPassword`/`hasViewOnlyPassword` 布尔。
- **端口固定不可调**：Port/HttpPort/GatewayPort 已从 configSchema 与设置页删除，设备端/App 各读取点全部硬编码（5901/5801/18081/8080）。

#### 底层互斥逻辑（配置 UI 设计依据）

> 互斥关系来自 `trollvncserver.mm` 实际逻辑，UI 显隐/校验必须遵守；反向模式（viewer/repeater）已全链路废弃，相关规则已删。

| # | 互斥/联动点 | 规则 | UI 处理 |
|---|---|---|---|
| 4 | VNC 认证 | `FullPassword` 为空=无认证；经典 VNC 只认前 8 位 | 密码组提示 |
| 5 | 全局只读 vs 只读密码 | 全局 `ViewOnly` 优先生效 | 标注优先级 |
| 6 | SSL 证书/私钥 | 必须成对，缺一不启用 TLS | 成对校验 |
| 7 | HTTP Port=0 | 关闭网页服务（端口已全固定，仅存档）| — |
| 8 | 脏区检测 | `FullscreenThresholdPercent=0` 关闭 | 进阶折叠 |
| 9 | 滚轮/保活 | `WheelStepPx=0`、`KeepAliveSec=0` 分别禁用 | 滑块带"0=关闭"说明 |
| 10 | 方向同步 | `OrientationSync` 控制画面采集方向跟随设备物理方向 | 设置页标注 |

> 已废弃：#1 工作模式三选一 / #2 反向模式 vs 本地能力 / #3 Viewer vs Repeater / #11 Bonjour 依附反向（反向模式全链路删除，无残留）。
> 扩展：远程 `set` 配置后，本地 UI 需监听 NSUserDefaults 变更并同步显隐状态。

### 3.6 触控坐标归一化

- 触控参数一律 **0-1 归一化**（`(0.5, 0.5)` = 屏幕中央），跨设备脚本可复用；设备侧转原生像素：`nativeX = normalizedX × screenWidth × nativeScale`。
- **边界约束**：坐标超出 0-1 或缺 x/y → 设备侧返回错误，不执行；App 锁定竖屏，无物理旋转场景。
- AI 工具基于截图判定坐标时，以截图实际帧缓冲尺寸换算归一化坐标（Scale 影响 RFB 传输尺寸，Scale 变更后设备重新 register 推送新 screen）。
- 触控不进能力菜单，画布直操（RFB pointer 事件）。

### 3.7 输入与键盘（方案 C，2026-08-16 定型）

- **设备端**：keyDown/keyUp 直接映射，**不补 Shift**。
- **前端**：Shift 状态跟踪（`kbdShiftHeld` + **400ms 空闲自动释放**）；特殊键 **down + 60ms 按住 + up**；删除/回车/粘贴前先释放 Shift；**CapsLock 两态开关**；英文/数字键值直发。
- **中文/emoji 输入走 `type.paste`**（写剪贴板 + 模拟 Cmd+V）；剪贴板首次复制 = start 基线同步读取（无 changeCount 锚点）。
- 剪贴板能力三件套（走 invoke，不走 RFB 剪贴板扩展）：`clipboard.get`（设备 → 控制端读取）、`clipboard.set`（控制端 → 设备写入）、`type.paste`（写入 + 模拟粘贴，原子通道）。

### 3.8 新增能力流程

- **设备端**：`TRCapabilityRegistry` 注册 executor（invoke 通道自动生效）。
- **前端**：`caps.js` 定义数组加一条（KEY_DEFS / BATCH_CAPS / CONFIG_DEFS 按需选入）。
- 两端约定对齐，**无运行时发现**；网关自动转发，API 自动暴露；禁止前端调用设备端未注册的能力 id（宪法 10.3）。

## 4. 隧道与连接

### 4.1 18181 隧道

- 设备注册成功后由 TRGatewayClient 触发自动建立（`TRTunnelClient` 单例）；网关侧独立 `net.createServer`（`tunnels[deviceId]` 索引）。
- **握手**：设备发起后首包 `{"type":"tunnel_hello","deviceId","token"}` → 网关校验 → `tunnel_ack` → 之后帧封装（JSON 行首包握手 + 裸字节透传）。
- **FT_ 帧协议**：`FT_DATA 0x01` / `FT_PING 0x02` / `FT_PONG 0x03` / `FT_CMD 0x04` / `FT_CMDACK 0x05`。
- **心跳与重连**：30s 心跳；断线退避重连（2s→30s），与注册通道一致。
- **流量路由**：`/ws/vnc/:id` 画面流量与命令流量**唯一走** `tunnels[deviceId]`；无隧道直接拒绝（**4003**），**无直连回退**；命令通道隧道优先、注册通道回退。
- **离线判定**：隧道断开即标记设备"跨网络不可达"，但局域网直连仍可用；设备在线 = 注册连接存活或隧道连接存活。

### 4.2 会话管理（ack 驱动握手）

- **ack 驱动握手**：网关 WS 会话建立触发 `rfb.start(id)` → 设备同步 connect 本地 5901，ack 回 `ok=connect` → 网关收到匹配 id 的 ack 才精确放行缓冲的握手字节（3s 超时兜底，兼容旧设备）；connect 失败显式 close ctrl 会话（**4005** "画面服务不可用"，不静默黑屏）。
- **同设备单活跃会话**：设备仅 1 条隧道 + 1 个 5901 连接；网关新会话**顶掉同设备其他非 ctrl 会话**（**4001** preempted by new session），按"首会话"触发 5901 重建保证干净握手。
- **末会话退出**：延迟 **800ms** 下发 `rfb.stop`（防快速进出乒乓抖动），并清理 pending 缓冲（重建分支丢弃旧 pending，防旧帧被当版本响应解析）。
- 隧道断开会话异常时网关关停 WS 会话（**4002** tunnel closed）；设备端 `_passthroughLoop` 本地 5901 EOF 时仅清理 fd 回 standby、隧道保持常驻，不退出重连。

## 5. 命令与前端契约速览

> **唯一真相源**：设备端 `TRCapabilityRegistry.mm`（executor 注册：`_registerControl:` 28 处 ≈35 项、`_registerConfig:` 44 处）与前端 `trollvnc-farm/web/caps.js`（KEY_DEFS / BATCH_CAPS / CONFIG_DEFS）——**文档不复制清单**，增删能力只改代码，详见 02 §3。

- **前端入口现状**：KEY_DEFS **10 键**（RFB ks/code 直发；按压语义 = 单击立即发送 + 长按 800ms，双击/三击自然连点）；卡片 ⋯ 菜单仅「编辑/删除」；批量操作 = batch/invoke|configs|restart（restart 二次确认）；动作区已整区移除。
- **剪贴板/文本**：clipboard.get / clipboard.set / type.paste（中文/emoji 输入统一走它）。
- **屏幕感知**：screen.hash（卡片墙 hash 门控消费）；screen.diff / screen.waitStable 已删注册（不回归）。
- **服务/设置**：service.restart、settings.generateKeys、settings.searchGateway。
