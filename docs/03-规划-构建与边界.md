## 1. 构建与交付

### 1.1 构建路径（当前）

```
改源码（TrollVNC 子目录） → push 本仓库 main 分支
  → GitHub Actions "Build SuperPhone"（macOS CI）→ 下载 packages-bootstrap 产物
  → 得到 TrollVNC_0.0.1.tipa → TrollStore 安装 → 真机验收
```

- **仓库**：2026-08-15 单仓库化（TrollVNC 由 gitlink 降级为普通子目录，旧 git 历史 `.git.bak` 不入库）；远程 `superphone` → `github.com/78725449/SuperPhone.git`，开发分支 `release`；build.yml 在仓库根 `.github/workflows/`，所有 run 步骤 `working-directory=TrollVNC`
- **触发**：push `main` 分支自动构建；`workflow_dispatch` 手动触发（可带可选输入，见 1.3）
- **版本**：0.0.1（Makefile `PACKAGE_VERSION`）；push 触发时 release job 自动创建 `v0.0.1` tag + GitHub Release（body=`TrollVNC/CHANGELOG.md`，`permissions: contents: write`）
- **产物**：`TrollVNC_0.0.1.tipa`（bootstrap scheme，TrollStore 安装）+ `packages-bootstrap` artifact（zip）；其余 3 个 scheme 产物为 .deb
- **Windows 本地不能构建**（Theos/ldid 依赖 macOS），出包只能走 CI

### 1.2 Theos 4 方案

| scheme | THEOS_PACKAGE_SCHEME | 产物 |
|---|---|---|
| default | legacy | .deb |
| rootless | rootless | .deb |
| roothide | roothide | .deb |
| bootstrap | bootstrap | .tipa（最终安装产物）|

- CI 构建：`source devkit/<scheme>.sh` + `FINALPACKAGE=1 gmake clean package`（bootstrap 编译失败时附带 xcodebuild 诊断步骤）
- 本地四方案构建：`devkit/build-all.sh`（需 macOS Theos 环境）

### 1.3 CI 可选输入（workflow_dispatch）

- `is_managed`（bool，默认 false）：为 true 时经 `devkit/gen-managed-plist.sh` 生成 **Managed.plist** 打入包内（Managed 配置打包）
- 配置输入：`desktop_name`（默认 SuperPhone）、`port`（默认 5901）、`view_only`、`scale`（0.1–1.0）、`frame_rate_spec`（如 60 / 30-60 / 30:60:120）、`modifier_map`（std / altcmd）
- 可选 secrets：`TVNC_FULL_PASSWORD` / `TVNC_VIEWONLY_PASSWORD` / `TVNC_GATEWAY_HOST` / `TVNC_GATEWAY_PORT` / `TVNC_GATEWAY_TOKEN`（网关预置，跳过 App 初始化页）

### 1.4 部署

- 服务器（网关/控制台）部署在**软路由 docker**：见 `trollvnc-farm/deploy/`（`trollvnc-farm/deploy/openwrt-docker.md` / `trollvnc-farm/deploy/openwrt-native.md`）
- 服务器侧改动走 `trollvnc-farm` 仓库，本地 `npm test` + 冒烟测试验证后再上软路由

## 2. 明确不做（内网自用边界，与宪法 1.3 一致）

| 项 | 说明 |
|---|---|
| 注册鉴权 | 内网可信，不设设备鉴权；网关侧 FARM_TOKEN 兜底 |
| 过度 Agent 命令通道 | 批量启停 / 远程装 App 等不在范围内（如需另立项目）|
| TLS 加固 | 内网自用不做公网加固；网关 https 已启用（自签证书 + 明文 301 跳转），frp 只做传输 |
| 多租户 / 审计 / 计费 / 商业化 | 不做 |

> 已实现、不属于"不做"范围：配置命令通道（set / configs API）、远程启停（restart 命令）；早期"能力清单上报"机制已废弃（前端为自包含静态契约，见宪法铁律 2）。
