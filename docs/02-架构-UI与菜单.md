## 1. 三端 UI 分工

| 界面 | 定位 | 卡片墙 | 大屏操控 |
|---|---|---|---|
| PC web 控制台（≥901px） | 多设备墙 + 聚焦大屏操控 | **H5 hash 门控变化拉图**（screen.hash 比对，变化才 screenshot，静止零图片流量） | 屏幕右侧**操作列**（按键区 + 同步/全屏/断开） |
| 手机 web 控制台 | 多设备墙 + 大屏操控 | 同上 | **悬浮按钮（FAB）** → 纵向列表操作菜单 |
| IPA 控制端（控制 Tab） | **WKWebView 容器**加载网关 H5 手机控制台（`TVNCConsoleWebViewController`） | 同上（网页端承担） | 同上（网页端承担） |
| 5801 电脑访问 | 单设备直连（无卡片墙） | — | **右侧操作栏**（`#bar`，BAR_KEYS 13 键常量渲染，贴画布右缘） |
| 5801 手机访问 | 单设备直连（无卡片墙） | — | 全屏 + **悬浮按钮** → 按键操作面板（`#panel`，同一份 BAR_KEYS 渲染） |

**核心原则**：

- 能力菜单统一为**纵向列表分组菜单**（按 category 分组），差异仅在触发方式与图标/名称的显示形式。
- IPA 控制端**整 Tab 替换为 WKWebView 容器**加载网关 H5 手机控制台——原生设备墙（TVNCControllerViewController）与大屏（TVNCViewerViewController / TRWallTileWebView）**已删除**，所有交互组件统一由网页端承担；改 Web 端即生效（serveStatic no-cache + `app.js?v=N` 版本参数），App 容器自动同步。
- 前端为**自包含静态契约**：caps.js 定义数组驱动（KEY_DEFS/BATCH_CAPS/CONFIG_DEFS），**无上报、无元数据表、无运行时发现**；register 仅上报 deviceId/name/vncPort/httpPort/screen/configs。

## 2. 控制台布局与交互

### 2.1 顶部导航

| 端 | 组件 |
|---|---|
| PC | 卡片滑杆（`#cardwRange`）、布局切换（PC 端隐藏）、刷新、直控、批量操作、+ 添加设备、设备统计（`.meta`） |
| 手机（≤900px） | 仅**「批量操作」+「布局切换」**两个组件，其余全部隐藏（滑杆/刷新/直控/添加设备/统计） |

### 2.2 设备卡片墙（wall-grid）

- **宽度滑杆**：`#cardwRange` 160–400px、步进 5、默认 280px（localStorage `farm_cardw` 持久化）；运行时 `computeCardWBounds()` 按容器宽度反推滑杆范围——最小固定 110px（约 15 列）、默认固定 175px（约 10 列）、最大动态（每行 5 列），resize 重算并钳制当前值。
- **平铺模型**：`#wall` = `repeat(auto-fill, minmax(var(--card-w),1fr))` + `.tile{width:auto}`——任意窗口宽度下卡片拉伸填满整行（grid stretch 紧挨无空隙）、从左到右逐行、第一行排满自动换行。
- **高宽比**：`.tile` 用 `height:0 + padding-bottom:%`（padding 计入 grid 行高；CSS `aspect-ratio` 不贡献行高会引发卡片重叠，禁用）；默认按多数设备屏幕比例分组取值（0.01 精度），横/竖屏手动切换覆盖；`devicesSignature()`（在线设备 id + 屏幕尺寸）变化才重算，避免每次轮询重排。
- **离线置灰**：离线设备卡片显示最后在线时间与离线占位，不可控制。
- **排序**：卡片排列位置由设备 ID 排序号决定（见 2.11 编辑设备，0–99999，越小越靠前，留空按注册时间）。
- 隐藏滚动条（`scrollbar-width:none` + `::-webkit-scrollbar{display:none}`）；聚焦态侧墙固定 `width: calc(var(--card-w)+12px)`。

### 2.3 卡片 ⋯ 菜单

仅两个操作：**编辑**（改名 + 改排序号）与**删除**。无能力分组菜单、无 ⚙ 设备配置入口（配置入口已随 QUICK_CONFIG_GROUPS/showConfigPanel 一并删除）。

### 2.4 聚焦大屏（focusPanel）

- 头部：状态圆点（**蓝=已连接 / 红=已断开**，`focusStatusDot.on/.off`）+ 标题 `设备名 (host:port)`。
- **连接中浮层**：进入聚焦即显示画布中央旋转加载动画（与 5801 直连页一致的 `#status` 样式）；连接成功收到首帧后隐藏。
- **断开自动重连**：聚焦主控画面断线（iOS 后台挂起/切应用致 WS 断开 1006）自动调度重建——断开立即重连，失败后 2s 防抖；主动断开（1000/1001）与被其他端接管（4001）不自动重连；重连期间浮层显示「画面已断开，正在重连…」。
- 聚焦会话 = **ctrl RFB 连接**（可操控，经隧道）。

### 2.5 操作列（focusOps）

顶部为**按键区**（KEY_DEFS 10 键，`renderCapOps` 渲染，仅图标）+ `hr` 分隔 + **🔗 同步 / ⛶ 全屏 / ⏹ 断开**三个静态按钮。

- 无「返回」按钮（返回由断开承担，PC 端退出聚焦即回设备墙）；**无「适配」按钮**——适配为自动行为：`createRfb` 统一 `scaleViewport=true` 等比 contain，无独立按钮。
- 操作列去除分组标题（`.focus-ops-cap .cap-group-title{display:none}`，移动端悬浮菜单标题保留）；滚动条主题色（Firefox `scrollbar-color: var(--line)`；WebKit 6px 圆角 + 悬停 accent）。
- 手机端悬浮菜单 = 同一份按键区渲染（图标 + 名称）+ 「全屏 / 断开」静态按钮。

### 2.6 直控模式（directBtn）

**入口**：批量操作按钮左侧「直控」按钮；**两态**：激活 = 主题蓝高亮（`direct-active`）+ 显示设备数「直控 (N)」，再次点击退出。

- 进入 = 为**全部在线真实设备**（source=register，排除虚拟/离线）建立**非 ctrl 可输入 RFB**（互不抢占、输入直达设备 5901）；新上线设备自动补建（`startDirectRfb`）。
- 直控期间：悬停放大与「点击进入控制」引导失效；点击卡片**直达 RFB 控制**（canvas 输入由 noVNC 处理），不聚焦。
- 退出 = 关闭全部直控 RFB（**必须真正 close WS**，防残留会话堆积）→ 恢复截图轮询；单设备直控断开（离线/隧道断/服务端断开）→ 清理标记 → 恢复轮询 → toast 显示断开码（4001/4002/4005 等）便于诊断。
- 互斥：直控时聚焦与悬停效果失效；同步仅在非直控、聚焦后才有；批量操作不受影响。
- **服务端硬约束（同设备单会话）**：设备端仅 1 条隧道 + 1 个 5901 连接，**同设备同时只允许 1 个活跃会话**——`handleVncSocket` 新会话建立时顶掉同设备其他非 ctrl 会话（4001），随后按"首会话"语义触发 5901 重建保证干净握手。多会话共享 5901 会导致协议串流（noVNC `Unexpected server message (type N)` 断开）。会话退出时网关 `rfb.stop` **延迟 800ms 下发**（debounce，防 stop/start 乒乓）。
- 画面适配：直控/同步推流 canvas 由 noVNC `scaleViewport` 等比缩放**居中**（`left:50%; top:50%; translate(-50%,-50%)`），与截图缩略图 `object-fit:contain` 显示位置一致（模式切换无跳变）。

### 2.7 同步控制（群控广播，PC 端）

- 入口：聚焦大屏操作列「🔗 同步」按钮；**两态**：激活变红（`sync-active`），图标恒为 🔗（不变 ✕）。
- 进入同步选择模式：点卡片即切换同步（无复选框），选中态 = 边框高亮 + 中央「同步中」徽标（不遮挡推流、不可触控）。
- 同步设备建立 `grp=wallSession&viewOnly` RFB 订阅：卡片实时推流（显示同步执行情况）+ 作为广播接收成员；**主控始终携带 `grp+broadcast`** → 勾选/取消同步不重建主控连接，主控画面零跳动。
- 仅聚焦状态下可用；主控设备本身不可同步；离线设备不可同步（提示）。
- 退出聚焦/退出同步模式：关闭全部同步 RFB 订阅 → 恢复截图轮询。

### 2.8 批量操作（batchBtn）

- 点击进入多选模式（卡片出现 checkbox，顶部按钮变「已选 N 台 / 取消」两态）→ 勾选设备后再次点击弹出**批量菜单**。
- 批量菜单按 `groupByCategory(BATCH_CAPS)` **按 category 分组**渲染（分组标题用 `CATEGORY_LABELS`）；操作 = **调用能力**（batchInvoke，无参能力直接下发）/ **批量配置**（batchSetConfigs）/ **批量重启**（batchRestart，**二次确认**弹窗）。
- 批量清单 = BATCH_CAPS 20 项静态定义（硬件按键类 + 服务/原生管理类），不含触控/文本/剪贴板/截图类。

### 2.9 布局切换（卡片 / 列表两档）

- 窄样式图标按钮 + ▾，两档菜单：`卡片`（宫格）/ `列表`（单列行）；按钮图标随选中项切换（grid=四宫格 / list=三横线）。
- 布局状态 localStorage `farm_layout` 持久化；**PC 端（≥901px）恒为卡片宫格**（布局按钮 PC 端隐藏）。
- 卡片视图：移动端固定 2 列、卡片填满列宽（`width:auto`，grid item stretch）、`--tile-pb` 比例自适应继续生效。
- 列表视图：单列行式，行高 64px = 48px 缩略图（.tv）+ 设备信息行（状态点+名称+⋯+状态文字）+ 批量 checkbox。
- 移动端坑位（已修复的约束）：`#workspace` 必须 `align-items:stretch`（flex-start 使 `#wall` 宽度收缩为内容宽）；移动端卡片宽禁止沿用 PC 端 `--card-w`（`computeCardWBounds` 在窄视口会算出 115px 小卡片）。

### 2.10 移动端 FAB（悬浮按钮）

- 单个**圆形白色 WiFi 信号按钮**（三弧 SVG），整钮可拖动（pointer 拖拽 + 6px 位移阈值区分拖动/点击，安全边界含 safe-area），点击（未拖动）展开/收起操作菜单。
- **信号强度色**：控制会话期间每 3s `command ping` 测设备往返延迟——`<150ms` 全弧绿 / `<400ms` 中弧+点黄 / 更差或失败仅点红（未亮弧浅灰），title 显示延迟 ms。
- 菜单定位 `positionOpsMenu()`：按 FAB 位置动态定位（优先 FAB 下方、空间不足上方），按可用空间裁剪 max-height + 滚动，**任何情况下不覆盖悬浮按钮**；拖动 FAB/窗口 resize 时菜单实时跟随重定位。
- 菜单收起监听用 `document pointerdown`（先于 touch 事件派发，不受 noVNC gesturehandler preventDefault 影响）。

### 2.11 添加 / 编辑设备

- **添加设备** modal：名称、IP/主机、端口（**默认 5901**）、分组（可选）、备注（可选）。
- **编辑设备** modal：ID（**排序号 0–99999**，越小越靠前，留空=清除按注册时间排序）+ 名称（非空校验）；保存 = PATCH 网关 → 刷新设备墙。ID 不显示，仅决定卡片排列位置。

### 2.12 控制端键盘（方案 C，2026-08-16 定型）

- **「键盘」键 = 单向固定**：点击发 `XF86Keyboard`（0x1008ff2e）收起被控端软键盘；触控端随后 `focusKbdInput()` 调起**控制端**软键盘（电脑端有实体键盘，不调）。被控端键盘完全由被控端系统管理（点被控画面输入框才弹），控制端不注入 attach/detach。
- **输入源**：`#kbdInput` 固定全屏透明层 input（color/caret 透明、pointer-events:none 不挡画布触控；必须位于可视视口内 iOS 才弹键盘）——iOS 软键盘唯一可靠事件源是 input/composition 事件（无 keydown/keyup）。
- **字符注入**：
  - 英文/数字（单可打印 ASCII）→ **键值直发**（`kbdSendAscii`）：前端**Shift 状态跟踪**（需 Shift 且未持有 → `Shift_L(0xffe1)↓` 置持有；不需要且持有 → 抬；连续大写期间保持按下不抬）；字符键 down + 50ms + up；停止输入 **400ms 空闲自动释放 Shift** 防残留。设备端 keyDown/keyUp 直接映射**不补 Shift**（方案 C 分工）。
  - 中文/emoji/多字符 → `type.paste` 能力注入（写被控端剪贴板 + releaseEveryKeys + 模拟 Cmd+V，被控端弹一次系统隐私确认后落入聚焦输入框）；**粘贴前释放 Shift**。
  - 特殊键（删除/回车）→ 特殊键 down + **60ms 按住** + up 直发（`kbdSendSpecial`），发送前释放 Shift；删除 = 向被控端发一次 Backspace（删除被控设备内容，非本地）。
  - compositionend 整段提交；compositionend 后 60ms 短窗口忽略 iOS 乱序补发 input；`#kbdInput` 占位空格保证删除键始终触发 input（iOS 空 input 上删除键无事件）。
- 触屏能力判定（`isTouchable`）仅用于"自动弹控制端软键盘"，按钮行为本身无判定。

## 3. 菜单与能力契约

### 3.1 按键对象（KEY_DEFS，10 键，RFB 直发）

> 唯一真相源 = `web/caps.js` KEY_DEFS（10 键：power / home / volup / mute / voldn / briup / bridn / snapshot / spotlight / keyboard）。每个按键 = 对象（key/title/icon/svg + events 按压模式映射），keysym 值见宪法 7.2。本文只记录语义：

- **直发通道 = 画布同一 noVNC RFB 连接**（sendKey/sendPointer，无 HTTP、无能力回退）；无连接时按键不可用。
- power 走 **ptr:2 中键**（PointerEvent）；其余走 keysym（XF86 系列见宪法 7.2）。
- 图标为 SF Symbols 风格内联 SVG（stroke=currentColor 跟随主题色，viewBox 24×24），无 SVG 回退 emoji。
- hwlock/hwunlock/releasekeys（硬件键盘锁/解锁/释放按键）**不在按键区**，仅存在于 BATCH_CAPS（批量入口）。

### 3.2 按压语义（press.js PressRecognizer，前端一处实现）

PC/手机/卡片共用同一组件，按 keyDef.events 声明式驱动：

| 模式 | 语义 |
|---|---|
| click | 短按抬起立即发送，**零延迟** |
| long | 按住 **800ms** 触发 |
| double / triple | 仅 events 声明了该字段的按键才启用 **300ms 多击窗口**（分级判定：三击 → 双击 → 单击）——**现状仅批量入口显式能力保留，按键区已无 double/triple**；无该字段的按键双击/三击 = **自然连点**（每次点击独立立即发送，iOS 系统层识别，无判定延迟） |
| down / up | 有该字段的按键（音量/亮度/静音）按下触发 down、松开触发 up；**一次短按 = down+up 一格，不补 click**（避免一次短按注入 down+up+click 三次导致设备端双响应，如音量跳两格） |
| 取消 | pointercancel（滚动/来电/手势打断）复位状态，不触发 click/多击计数；卸载时兜底清理长按/多击定时器 |

### 3.3 批量能力清单（BATCH_CAPS，20 项静态定义）

> 唯一真相源 = `web/caps.js` BATCH_CAPS（20 项：hid 硬件按键 17 项，含 home.*/power.* 多击与 hwlock/hwunlock/releasekeys；service.restart 1 项；settings.generateKeys/searchGateway 2 项）。按 category 分组渲染（`groupByCategory` + `CATEGORY_LABELS`）。

批量菜单**不含触控/文本/剪贴板/截图类**；restart 类操作二次确认。

### 3.4 配置表单定义（CONFIG_DEFS，37 项）

> 唯一真相源 = `web/caps.js` CONFIG_DEFS（37 项：key/title/type/min/max/step/enum/reload 自包含 schema），**与设备端 `_registerConfigSchemas` 对齐**；`CONFIG_BY_KEY` 为 key 索引 Map。文档不复制清单，增删配置只改 caps.js。语义：

- 按 reload 策略分区：hot（热生效）/ instant（即时）/ restart（重启生效）/ gateway（网关侧生效，如 BonjourEnabled/GatewayHost/GatewayToken）。
- **端口项不在定义中**：Port/HttpPort/GatewayPort 全固定不可调（8080/18081/18181/5801/5901），configSchema 已删 → 菜单天然不出现。

### 3.5 传输 API 封装（caps.js）

> 唯一真相源 = `web/caps.js` 导出函数：`invokeCap` / `setConfigs` / `batchInvoke` / `batchSetConfigs` / `batchRestart` / `groupByCategory` / `CATEGORY_LABELS`。对应网关端点见宪法 7.4（单台 invoke/configs/restart/ping + 批量端点）。本文不复制签名。

### 3.6 能力分层与新增流程

- **分层**：primary = 人工遥控按键（KEY_DEFS 10 键）；secondary = 管理/查询/配置（BATCH_CAPS/CONFIG_DEFS）；internal = AI 底层原语（home.*/power.* down/up、consumer/hid 原语、screen.hash 等）——**不进任何菜单**，invoke 可用。
- **触控不进菜单**：画布直操（5801 RFB 指针已有；H5 直控 noVNC 已有；聚焦模式 pointer→touch 经画布）。
- **新增能力流程**：设备端注册表注册 executor（invoke 通道不变）+ 前端定义数组（KEY_DEFS/BATCH_CAPS/CONFIG_DEFS）加一条——两端约定对齐，**不做运行时发现**。

### 3.7 5801 直连页模式

- **按钮定义抽为一份 BAR_KEYS 常量渲染**（消除 PC `#bar` 与手机 `#panel` 双份 HTML），**13 键**：power / home / volup / mute / voldn / briup / bridn / **snapshot（截屏）** / **spotlight（搜索）** / kb（键盘）/ **paste（粘贴）** / full（全屏）/ disc（断开）。
  - 与旧版差异：clip → **paste**（粘贴输入，弹浮层 → 文本 → `pasteToDevice` 原子注入：写剪贴板 + 150ms 后释放残留修饰键 + 模拟 Cmd+V，与网关 type.paste 同机制）；**fit 已删**；新增 snapshot / spotlight。
- **独立 caps.js**（`layout/usr/share/trollvnc/webclients/caps.js`）仅在可加载时**覆盖按钮标题**（bar 用 textContent、panel 用 spans[1]），失败不影响连接——**已与网关 caps.js 分叉**，互不引用。
- 按压识别：tapKey 支持 hold/双击 keysym 序列；snapshot 设备端仅 down 时执行 snapshotPress，tapKey 发 down+up 一次。
- **无返回/同步按钮**：5801 为单机直连页（无设备墙概念），返回/同步仅存在于 PC focusOps（群控台场景）。
- PC 端操作栏 `position:fixed` 贴画布右缘（`syncBarPosition()` 按画布实际 rect 定位，画布 0×0 未出画面时隐藏）；手机端 FAB 与控制台同款白色 WiFi 信号按钮（直连页无网关 ping 通道，以同源 `./caps.js` no-store fetch RTT 为网络质量代理，阈值同控制台）；连接状态为画布**居中状态浮层**（连接中转圈 / 断开原因 / 连接失败，半透明黑底不挡操作）。
- 键盘：与控制台同方案 C（ASCII 键值直发 + Shift 状态跟踪 + 特殊键 60ms + 中文/emoji 走 pasteToDevice）。

## 4. 拉图与性能机制

### 4.1 hash 门控变化拉图（卡片墙帧获取，唯一机制）

- **不建 RFB 持久连接**：卡片墙无 viewOnly RFB 会话；每设备独立轮询实例（`inst.rfb = {kind:'screenshot', lastHash, silent}`）。
- 每个 `ThumbInterval` 秒（设备配置，默认 5s，可配 1–60s）先 `invoke screen.hash`（0.3ms 级轻量 pHash，5901 RFB 扩展消息承载）与 `lastHash` 比对——**变化才 `invoke screenshot` 拉帧渲染**；静止保持缓存帧，**零图片流量**。
- **双速退避**：变化后 1s 快检；静止按 `base × 1.5^silent` 退避至 **15s 封顶**。
- screen.hash 失败显式报错无回退（安装本 IPA 的设备均注册该能力）。
- 点击卡片进入大屏操控时切换为可操控 ctrl RFB 会话（经隧道）。

### 4.2 容器模式（IPA 控制 Tab）

- URL 构造：`?container=ipa&token={Token}&selfId={DeviceUUID}`——`container=ipa` 标记容器模式，`selfId` 用于设备墙**过滤自身设备**（卡片墙不显示本设备）。
- 前端暴露 `body[data-container="ipa"]`：CSS 可按容器差异分支（如 WKWebView 全屏限制下隐藏无关 UI）。
- 容器特性：WKWebView 加载 https + 自签信任；未配置引导 + 3s 自动轮询、加载失败重试、网关变更幂等重载、cleanup 释放。
- 版本同步：网关 `serveStatic` 带 `Cache-Control: no-cache` + 前端资源 `?v=N` 版本参数，改 Web 端即生效，App 容器自动同步。

### 4.3 会话模型与硬约束（网关侧）

| 会话类型 | 参数 | 语义 |
|---|---|---|
| 聚焦主控 | ctrl + grp+broadcast | 可操控；同设备互斥（新 ctrl 顶旧 ctrl 4001） |
| 同步订阅 | grp=wallSession & viewOnly | 实时推流 + 广播接收，不抢占 |
| 直控 | 非 ctrl 可输入 | 互不抢占，输入直达设备 5901 |
| 管理客户端 | cap.hello 标记 | 不计入 clients.count/list、不参与单会话互斥、不推画面帧 |

- 同设备单活跃会话（见 2.6）；会话退出 `rfb.stop` 延迟 800ms（防乒乓）。
- 离线检测：RFB 连接断开/失败标记卡片不可达（toast 断开码 4001/4002/4005 等）。

## 5. 样式与主题

- **聚焦画面余白透明化**：`.screen` 背景 transparent + 聚焦画布 `rfb.background='transparent'`，露出 body 背景（`--bg`），聚焦区无黑边/无组件残影。
- **深浅色跟随**：`@media (prefers-color-scheme: light)` 覆盖变量，深浅色自动切换。
- 图标：SF Symbols 风格内联 SVG（stroke=currentColor），渲染处 `(k.svg || escapeHtml(k.icon || '?'))`。
- 卡片高宽比用 padding-bottom 模型（§2.2）；noVNC canvas 等比 contain 居中（§2.6）。
