# 页面签名（资产 L1 页面表的第一块）

> **这是【入库的资产】，不是运行时缓存** —— 与 `data/skill-cards/`（运行时产生、不入库）不同类。
> 采集与判定工具：`scripts/page.py`（`snapshot` / `which` / `list`）。

## 它解决什么问题

一期跑「打开抖音搜南京美食」时暴露了三条约束（详见 `docs/known-issues/02-设备端与构建.md`）：

| 约束 | 现象 |
|---|---|
| `wait_for{hashDiff}` 热启动会超时 | App 已在后台且恢复上次页面时，`open` 是瞬时切换、画面不变 → 白等到超时并中止整条脚本 |
| `back`（边缘右滑）不是万能的 | 抖音搜索页不响应边缘右滑（连发两次，OCR 逐字相同）|
| **★ 缓存坐标需页面前置条件** | App 会恢复到上次离开的页面 → `tap{0.928,0.066}`（"首页的搜索图标"）在非首页会点到完全错误的东西 |

**三条的共同解 = 先回答「我在哪个页面」。**
设备端已有做判定的全部原料（`vision.ocr` 给文字+坐标+置信度、`screen.hash` 给 pHash），
**缺的只是"页面 → 特征文字"从哪来** —— 以前每次都要人读 OCR 手工挑词。

## 目录与格式

```
pages/<app bundleId>/<页面名>.json
{
  "page": "首页",
  "app": "com.ss.iphone.ugc.Aweme",
  "env": {
    "screen": "750x1334", "lang": "zh-Hans",
    "collected": "2026-09-19 04:12:38",
    "device": "553A6EA8-…", "samples": 3,
    "match": "substring"          ← ★ 匹配口径标记（旧格式没有这个字段）
  },
  "hash": "<采集时的 pHash>",
  "signature": ["三直播团购南京关注商城推荐", "消息", "朋友"],   ← ★ 只用【稳定词】
  "union":     ["…", "1.2万", "1322", "@蓝毛", …],              ← 诊断用，含内容词
  "rawCount": 20
}
```

## ★★★ 两个关键设计（都是实测逼出来的，不是设计的）

### 1. 必须【多次采样取交集】—— 分离"结构"与"内容"

只采 1 次时，签名里会混入大量**内容**（点赞数 / 视频标题 / 搜索结果）。

**实测**：抖音首页采 1 次得 17 个词，其中 12 个是内容 → **换一个视频后判定得分从 1.00 掉到 0.29**，
直接判不出页面（而且会误导性地提示"该采集新页面"）。

> **结构词每次都在，内容词每次不同 → 交集即结构。**
> **★ 这个分离是【自动】的，不需要人工标注哪些是结构、哪些是内容。**

实测效果：抖音首页 3 次采样，并集 38 词 → **稳定词 3 个**，剔除了 35 个内容词
（`1.2万` · `1322` · `@蓝毛` · `朋友才是游戏的高级配置！…` 等）。

### 2. ★ 必须用【子串匹配】，不能用【精确相等】—— OCR 分块边界不稳定

**实测（第三次迭代才发现）**：3 次采样取交集时得到**空交集（0 个共同文字）**，连"首页/朋友/消息"都没有。

**根因**：**OCR 的分块边界不稳定** —— 同一根顶部栏，
一次可能合成一块 `三 直播 团购 南京 关注 商城推荐`，另一次可能切成三块。
用"块字符串精确相等"求交集，必然得到空集。

> **→ 一律在【去空白的大串】上做子串匹配**，分块边界变化就不再有影响。
> **→ 另需过滤【过短词】**：单字（如"我"）几乎任何屏幕都含它，零区分度。

## 判定算法

刻意保持最简：`score = |签名 ∩ 当前大串| / |签名|`，取最高分且 ≥ 阈值（默认 0.6）者胜。
页面判定的本质就是"这页的特征文字在不在"，不需要复杂的相似度。

## 用法

```bash
python scripts/page.py snapshot 首页 --app com.ss.iphone.ugc.Aweme --samples 3 --verbose
python scripts/page.py which [--threshold 0.6]
python scripts/page.py list
```

**采集纪律**：
- 采集时**设备不能被人工接管**（`controlState` 非 `direct/gateway`）；护栏会挡住输入类操作。
- 采样之间工具会**自动滚动换内容**，结束后自动滚回原位。
- 若某页**没有可滚的内容**（如静态设置页），加 `--no-scroll`（否则交集仍=全集，含内容词）。
- 一个页面**换了 App 版本后应重采**（`env` 里记了采集时间，便于判断新鲜度）。
